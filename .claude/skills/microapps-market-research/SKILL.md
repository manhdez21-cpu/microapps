# Investigación de mercado
1. Buscar con WebSearch (modo estándar; extendido solo si el resultado es pobre). Lanzar búsquedas independientes a la vez.
2. Registrar en MARKET_RESEARCH.md: fuente (URL y fecha), hecho, y si es dato, estimación o suposición.
3. Separar siempre: real (citado) / estimado / simulado. Sin Trends ni Keyword Planner no hay volúmenes: decirlo.
4. Revisar reseñas negativas de competidores (qué falta, qué molesta) para priorizar funciones.
5. Terminar con riesgos y una recomendación accionable de una línea.
