# SEO de Microapps
- Cada app tiene `<title>` con la promesa, `meta description` (≤ 160 car.), `theme-color`, JSON-LD `WebApplication` y, si hay preguntas reales, `FAQPage` (el texto debe coincidir con el contenido visible).
- Contenido útil bajo la herramienta: fórmula explicada, tabla de referencia, FAQ. Debe coincidir con el núcleo de cálculo (hay pruebas que lo comparan).
- No añadir `canonical`, `sitemap.xml` ni `robots.txt` hasta tener dominio real (ver DEPLOYMENT.md).
- No afirmar volúmenes de búsqueda: no hay acceso a Search Console/Trends hasta que Manuel conecte la cuenta.
- Una página, una intención. Español neutro de Latinoamérica.
